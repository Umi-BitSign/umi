# Retired workflows and deployment records

The endpoint pilot and version 0.1 calibration enrollment are closed. Do not
follow their installation or enrollment steps for the current network. Use the
[miner instructions](../CURRENT_MINER_OPERATION.md) or
[validator guide](../PERMANENT_VALIDATOR_SUPERVISOR.md).

Dated readbacks describe their stated block only. They are not current network
status. Superseded procedures and deployment reports were removed from the
working documentation; the links below retain their exact pre-cleanup Git version.
Signed policies, release artifacts, receipts and attribution files were not changed.
